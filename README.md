# Personal Portfolio Website

This project is a responsive personal portfolio website created for Assignment 1. It presents information about my background, skills, projects, and contact information.

## Features

1. About Me and skills section
2. Two project cards with descriptions and placeholder images
3. Contact form with browser validation
4. Navigation between page sections
5. Responsive layout for desktop, tablet, and mobile screens
6. JavaScript greeting based on the visitor’s current time

## Technologies Used

1. HTML
2. CSS
3. JavaScript
4. Git and GitHub

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or additional software packages are required.
